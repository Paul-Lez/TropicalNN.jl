# TropicalNN.jl

TropicalNN.jl converts ReLU multilayer perceptrons (MLPs) to tropical rational functions. It provides tools to analyze their linear regions, monomial counts, and Hoffman constants.

For the mathematical background, see:

> Paul Lezeau, Thomas Walker, Yueqi Cao, Shiv Bhatia, and Anthea Monod.
> *Tropical Expressivity of Neural Networks.* arXiv:2405.20174, 2024.

## Installation

```julia
using Pkg
Pkg.add(url = "https://github.com/Paul-Lez/TropicalNN.jl")
```
